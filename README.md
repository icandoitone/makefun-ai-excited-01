**The Ocean in a Teacup** — a colossal golden koi bursts out of a tiny porcelain teacup, its leap spiralling water up into a burst of stars. One impossible scale twist: the whole ocean was hiding in a cup of tea. Entry for make.fun's "Make the AI judge excited" bounty — built to hit the judge with a jolt of awe at first sight, a surprise it did not see coming, and momentum driving up one golden diagonal.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the shipped image `entry.png` to `/output/entry.png` and self-checks it against the gate: a whole JPEG, at most 1 MiB and at most 1024 by 1024 pixels. It is deterministic — every run writes the same bytes — and uses no network.
